## FR-10 字段核对

`execution.sessionId/turn` 是原身份；`executor.id/version/protocolVersion` 是 Registry binding 中实际声明值；`lineage.parentSession` 保留 session 元数据，父/root execution 没有公开具体执行引用就 unavailable。`provider/model` 从 request/context 取；`time.startedAt/endedAt` 取原事件 Unix 毫秒；`result/terminalReason` 按源词汇；`error` 固定最小摘要；usage 各字段带 state/value/source/rule 或 reason。`provenance` 保留源类型、terminalSeq、DSH与Registry pin。unknown 没有凭空数值来源，估算也不能混充 reported。

## 一致性、隐私及仍需验证的风险

一个 group 由同一 global 镜像承载：摘要+原始执行身份。另一个 boundary 的安全方向是 dsh:session-log。失败时宁可原日志有、摘要缺，不接受摘要先存在。函数和 fixture 证明顺序机制，未证明目标后端所有竞态或物理断电。

源没有真实终结事件时不补造统计；源被外部删除后已有历史摘要不会自动撤销，属于本版本未覆盖的维护策略。达到5000条默认上限会停收并暴露错误，不静默丢旧身份。未提供跨进程同步写、保留期迁移、全量大数据流式导出和跨 turn 重试语义。

导出最小化但不是匿名化；sessionId 和 model/runtime 标识仍可关联。原始媒体由DSH持有，不进入本sidecar。导出默认关闭，真实用户权限与Connection边界验收尚未运行。样本里的凭据字符串全部为明确 synthetic 占位，不是真实秘密。未调用网络服务或真实模型，没有云费用、数据库或资金动作。
