## 工程定位与重现

代理自行测试仍必须隔离 HOME、CODEX_HOME、CLAUDE_CONFIG_DIR、HANAMESH_SHARED_HOME、HANAMESH_AGENT_HOME，临时根在 finally 删除；不要把下面本地入口直接装进 owner 的全局配置。启动浏览器必须遵守计划 §0；本轮没有启动浏览器。

本地市场：`codex plugin marketplace add <交付目录>/market-source` 后 `codex plugin add hanamesh-usage@hanamesh-session-g-preview`；Claude 对应 `claude plugin marketplace add <同一路径>`、`claude plugin install hanamesh-usage@hanamesh-session-g-preview`。只安装计量插件可看默认关闭/缺配置状态，不会凭空产生积分，也不能替代正式在线安装验收。

可从对应 main 重建：Core 构建后 `npm pack --ignore-scripts --pack-destination <交付目录>`；Usage 构建后 `node tools/package-agent.mjs <core.tgz> <新的插件目录>`。两仓分别执行 `pnpm run build`、`pnpm run test`、`pnpm run check`、`pnpm run test:mutations`。包验证：Core `pnpm run verify:pack <core.tgz>`；Usage `node tools/verify-agent-package.mjs <core.tgz>`。市场预备：文档站目录 `python3 -B prepare.py <市场Git仓> <新的站点输出> --base-url https://plugins.hanamesh.com`，只生成本地文件，不发布。
